ResearchCouncil · Public product brief

A research firm you can enter.

ResearchCouncil is a local-first investment research workspace with a clickable 3D office, durable evidence-backed memory, switchable model adapters, bounded scenario analysis, and paper-only decision records.

Public source note: This page is the sanitized shareable brief. Private working notes and personal portfolio observations are intentionally excluded.

Product goals

Local and durable

Run a React frontend and FastAPI backend on loopback. Persist records in SQLite and retain imported evidence with dates, hashes, and source locators.

GPT first

Use the authenticated Codex CLI through an existing ChatGPT subscription. Keep API-key routes and automatic local-model downloads disabled by default.

Evidence before claims

Keep sourced facts, calculations, model judgments, decisions, and simulations distinguishable. Missing or ambiguous data produces an explicit review or defer state.

Paper decisions

Research may lead to recommendations and monitoring conditions. The application never places orders or mutates an executed transaction ledger.

The office

The primary interface is a question journal with Results, Reddit and Watchlist views. Each card retains the original question or post title and opens its current decision, evidence, calculations and history. The optional office groups current work under Chief of Staff, Researcher and CIO, with selectable records and accessible controls. Earlier role records remain readable.

Research workflow

The Chief of Staff understands an open question or screens a Reddit post. The Researcher discovers public sources and assesses archived evidence alongside local technical indicators and price scenarios. One material public evidence gap can receive a bounded continuation in the same case. The CIO records Recommend with a supported entry and calculated shares, Watchlist with an observable price or catalyst condition, or Decline with reasoning. Missing inputs and execution failures remain separate from investment judgment. Events, source versions and prior decisions are retained so users can inspect where the flow stopped.

Memory and namespaces

SQLite stores accounts, observations, transactions, positions, source versions, research, decisions, model history, tasks, events, and simulations. The interface presents one research workspace. Test and simulation records remain separately scoped internally. Imported account observations remain unconfirmed until reconciled; unknown values are represented as unknown with a reason.

Optional data and models

Text, Markdown, CSV, and supported filing imports provide the dependable baseline. SEC retrieval is allowlisted and rate-limited. Optional quotes, options, local models, and schedules report their availability and freshness; unavailable inputs do not become invented claims. No third-party notifications or cloud database is required.

Open local operations

Install with ./install.command and start with ./start.command. The server is available at http://127.0.0.1:8000. Private SQLite plus evidence backups and JSON/Markdown exports are provided in scripts/. GitHub Actions checks the build without publishing the application.
